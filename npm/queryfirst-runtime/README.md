# queryfirst-runtime

Tiny runtime for code generated by Queryfirst. Wraps a `@pgtyped/runtime` `PreparedQuery` and enforces result cardinality.

- `one(q, name)`: `run()` returns the single row; throws unless exactly one row came back.
- `maybe(q, name)`: `run()` returns the row, or `null` for zero rows; throws if more than one.
- `none(q, name)`: `run()` discards any rows and resolves to `undefined`.

On a cardinality mismatch a `QueryfirstCardinalityError` is thrown, with `queryName`, `expected` and `actual` properties, e.g.
`Queryfirst: query "getUser" expected exactly one row, got 2`.

`@pgtyped/runtime` (^2.1.0) is a peer dependency. MIT licensed.
